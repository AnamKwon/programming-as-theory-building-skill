Deterministic failure confirmed. Root cause: `repository.py:195` orders only by `created_at DESC`. SQLite's `CURRENT_TIMESTAMP` has 1-second granularity, so rapidly-created orders share an identical timestamp and SQLite falls back to rowid-ascending order — the opposite of newest-first. No secondary `id DESC` tie-break. This is a genuine pagination-ordering defect, not flakiness.
