All files inspected and tests executed. I found a significant packaging defect: the entire `test_api.py` suite (15 tests) errors at fixture setup, while all 16 service-layer tests pass.

Root cause confirmed: `__init__.py` does `from .app import app`, which rebinds the package attribute `commerce_service.app` to the FastAPI **instance**, shadowing the submodule. So `test_api.py`'s `from commerce_service import app as app_module` gets the FastAPI object, not the module → `AttributeError: 'FastAPI' object has no attribute 'CommerceService'`. The app still loads under uvicorn (which resolves via `sys.modules`), so production runtime works; only the HTTP-layer tests are broken.
