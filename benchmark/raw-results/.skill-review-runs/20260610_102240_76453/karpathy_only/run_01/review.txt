All 25 tests pass, but I confirmed a critical defect: the **default runtime entrypoint is broken**. With the default `:memory:` DB, every `Repository` method opens a fresh `sqlite3.connect(":memory:")` connection — so the tables created in `_init_db()` vanish, and the README's documented `uvicorn src.commerce_service.app:app` command fails with `no such table: skus` on the first request. The tests pass only because `conftest.py` uses a temp **file** DB. I also found that `app.py` duplicates the entire route set at module level (lines 96–161) referencing an undefined module-global `service`.
