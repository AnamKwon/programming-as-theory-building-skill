**Key design highlights:**

- **Service layer** enforces all business rules: stock availability, idempotent reservation creation via idempotency keys, automatic reservation expiration, and order state transitions
- **Repository pattern** isolates SQLite operations behind a clean boundary
- **API security** uses header-based API key authentication (`X-API-Key: test-key-123`) for all mutations
- **Pydantic validation** ensures request payloads are well-formed with clear HTTP error responses
- **Comprehensive tests** cover happy paths, insufficient stock, idempotent retries, expired reservations, unauthorized access, and pagination
- **Pagination** on order lookup with configurable offset/limit (max 100)

The service is ready to run with `pip install -e .` and `uvicorn src.commerce_service.app:app --reload`, with tests via `pytest`.
