**Architecture highlights:**

- **Models** (`models.py`): SQLAlchemy ORM models (SKU, Reservation, Order, items) + Pydantic schemas for API validation
- **Repository** (`repository.py`): Data access layer isolating database queries
- **Service** (`service.py`): Business logic enforcing stock availability, idempotency, expiration, and state transitions
- **API** (`app.py`): FastAPI endpoints with dependency injection for service and auth
- **Security** (`security.py`): API key validation on X-API-Key header for mutations
- **Tests**: Comprehensive coverage of service layer and API endpoints with happy paths, error cases, and pagination

**Key features implemented:**
- Idempotent reservations (retrying with same key returns existing reservation)
- Stock reservation with release on cancellation or expiration
- Reservation confirmation creates confirmed orders
- Pagination for order listing with configurable skip/limit
- Clear HTTP error codes (403 auth, 404 not found, 409 conflict, 410 gone for expired)
- In-memory SQLite for development; configurable via DATABASE_URL
