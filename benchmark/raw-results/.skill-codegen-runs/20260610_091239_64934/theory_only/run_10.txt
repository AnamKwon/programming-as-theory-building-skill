**Architecture:**
- **Service layer** (`service.py`): Business logic with stock availability checks, idempotency via keys, reservation expiration, and order state transitions
- **Repository layer** (`repository.py`): Database access abstraction behind a clean boundary
- **Models** (`models.py`): SQLAlchemy ORM + Pydantic validation schemas
- **Security** (`security.py`): API-key authentication for mutations
- **FastAPI app** (`app.py`): Clean endpoint definitions with proper error handling

**Key features implemented:**
- SKU creation with initial stock and stock adjustments
- Reservation system with 15-minute TTL and automatic expiration checks
- Idempotent reservation creation via idempotency keys
- Reservation confirmation → order creation with stock movement (reserved → sold)
- Idempotent cancellation with automatic stock release
- Paginated order lookup (max 100 items per page)
- Comprehensive test coverage: happy paths, insufficient stock, idempotency, expiration, auth, pagination
