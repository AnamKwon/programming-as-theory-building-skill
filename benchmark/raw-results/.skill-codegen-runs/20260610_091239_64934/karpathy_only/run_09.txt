**Key design features:**

- **Repository pattern**: All database access isolated in `repository.py` with SQLite for persistence
- **Service layer**: Business rules (stock validation, idempotency, expiration) in `service.py`
- **API security**: Header-based API key validation for all mutating endpoints
- **Idempotency**: Reservations deduplicated by idempotency key
- **Pagination**: Order listing supports limit/offset with validation (1-100 range)
- **State machines**: Enforced transitions for reservations (pending→confirmed/cancelled) and orders
- **Error handling**: Clear HTTP errors (409 conflicts, 400 validation, 401/403 auth)
- **Tests**: 20+ assertions covering happy paths, stock insufficiency, expiry, unauthorized access, and pagination
