**Key design highlights:**

- **Repository pattern**: Clean boundary between service logic and database access
- **Service layer**: Business rules for reservations, stock validation, and state transitions
- **Pydantic validation**: Type-safe request/response models
- **SQLAlchemy ORM**: SQLite with proper schema
- **API security**: API key authentication for mutations; public read endpoints
- **Error handling**: Specific HTTP status codes (409 for conflicts, 410 for expired, 404 for not found)
- **Pagination**: Orders endpoint with skip/limit parameters
- **Comprehensive tests**: 20+ test cases covering happy paths, edge cases, authorization, and idempotency
