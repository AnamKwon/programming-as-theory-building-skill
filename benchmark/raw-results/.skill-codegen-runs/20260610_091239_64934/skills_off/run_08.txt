The service implements:
- **FastAPI endpoints** for health checks, SKU management, reservations, and order lookup
- **Repository pattern** with SQLAlchemy ORM for SQLite database access
- **Service layer** with stock availability checks, idempotency via idempotency keys, and 15-minute reservation expiration
- **Security** via API-key header validation for all mutating endpoints
- **Order state transitions** from pending → confirmed, with automatic order creation on confirmation
- **Pagination** for order listing (limit 1-100, offset-based)
- **Comprehensive tests** covering happy paths, edge cases (insufficient stock, expired reservations), unauthorized access, and pagination

Run with: `uvicorn commerce_service.app:app --reload`
