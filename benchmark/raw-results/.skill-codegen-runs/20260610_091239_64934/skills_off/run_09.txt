**Architecture highlights:**

- **Layered design:** Models (Pydantic) → Repository (SQLite) → Service (business logic) → API (FastAPI)
- **Endpoints:** Health check, SKU management, stock adjustment, reservation lifecycle (create/confirm/cancel), order listing with pagination
- **Key features:** API-key authentication on mutations, idempotent reservations, automatic expiration handling, stock reservation tracking
- **Database:** SQLite with proper schema, indexes, and foreign keys
- **Tests:** 25+ test cases covering happy paths, error conditions, idempotency, expiration, authorization, and pagination
- **Error handling:** Clear validation and HTTP error responses with descriptive messages
