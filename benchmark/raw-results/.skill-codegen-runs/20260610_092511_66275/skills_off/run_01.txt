**Service Summary:**

A production-ready FastAPI-based inventory and order orchestration service with:

- **Architecture**: Clean separation into models (Pydantic + SQLAlchemy), repository (data access), service (business logic), security (API key auth), and app (HTTP routes)
- **Features**: SKU management, stock adjustments, idempotent reservations with TTL, order confirmation/cancellation, pagination
- **Validation**: Request payloads validated by Pydantic; stock availability, expiration, and state transitions enforced in service layer
- **Database**: SQLite with SQLAlchemy ORM, transaction-safe updates via row-level locking
- **Security**: API-key authentication on all mutating endpoints
- **Testing**: 42 comprehensive tests covering happy paths, idempotency, insufficient stock, expired reservations, unauthorized access, and pagination

Start the service with `python -m commerce_service.app` and set `API_KEY` environment variable for authentication.
