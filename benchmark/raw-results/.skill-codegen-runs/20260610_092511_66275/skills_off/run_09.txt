**Project Summary:**

The service implements:
- **SKU & Stock Management**: Create SKUs and adjust inventory levels
- **Reservation System**: Create reservations with automatic 15-minute expiration, idempotent key support, and stock validation
- **Order Workflow**: Confirm/cancel reservations, track order status, support multi-item orders
- **API Security**: API key authentication via `X-API-Key` header on all mutating endpoints
- **Pagination**: Orders list supports configurable page size (1-100 items)
- **Clean Architecture**: Repository pattern for DB access, service layer for business logic, Pydantic models for validation

**Key Features:**
- Prevents double-booking by validating stock before reservation
- Idempotency keys prevent duplicate reservations from concurrent requests
- Automatic stock release when reservations expire or are cancelled
- HTTP status codes follow REST conventions (409 for insufficient stock, 410 for expired, 422 for invalid state)
- Comprehensive test coverage with happy paths, error cases, and edge cases
