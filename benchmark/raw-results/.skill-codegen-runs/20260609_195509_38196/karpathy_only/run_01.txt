**Architecture Overview:**
- **Service Layer** (`service.py`): Business logic with inventory reservation state machine, TTL expiration, and idempotency checks
- **Repository Layer** (`repository.py`): SQLAlchemy ORM abstractions for clean data access
- **API Layer** (`app.py`): FastAPI endpoints with Pydantic validation and HTTP error mapping
- **Security** (`security.py`): API key header validation for mutation endpoints
- **Models** (`models.py`): Unified Pydantic/SQLAlchemy definitions

**Key Features Implemented:**
- Idempotent reservations with duplicate detection
- Reservation TTL with expiration validation  
- Concurrent reservation accounting (available stock = total - all active pending/confirmed)
- State machine: pending → confirmed or cancelled
- Inventory deduction on confirm, restoration on cancel
- Pagination with limit/offset on order listing
- Clear error codes: 404 not found, 409 conflict, 403 unauthorized

**Tests Cover:**
