**What was built:**

**Core Service Features:**
- SKU and stock management with creation and adjustment endpoints
- Reservation system with 1-hour expiration, idempotency keys, and automatic expiration handling
- Order confirmation workflow that converts reservations to orders
- Pagination support for order lookups

**Architecture:**
- **App layer**: FastAPI with 8 endpoints handling HTTP requests/responses
- **Service layer**: Business logic including stock availability, reservation expiration, and state transitions
- **Repository layer**: SQLAlchemy-based database access abstraction
- **Models**: Pydantic schemas for API validation and SQLAlchemy ORM models for persistence
- **Security**: API key authentication (X-API-Key header) for all mutating endpoints

**Test Coverage (32 tests):**
- 15 service layer tests validating business rules (stock, expiration, idempotency)
- 17 API endpoint tests covering authorization, error cases, and pagination

**Database:**
- SQLite for simplicity with proper SQLAlchemy integration
- Automatic schema creation on startup
- Repository pattern allows easy swapping to PostgreSQL/MySQL later
