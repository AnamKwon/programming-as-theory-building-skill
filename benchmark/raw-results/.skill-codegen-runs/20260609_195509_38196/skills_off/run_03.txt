**Key features implemented:**

- **FastAPI service** with 9 endpoints for health, SKU, reservation, and order operations
- **SQLAlchemy ORM** with SQLite backend, repository pattern isolating data access
- **Pydantic v2** validation for all request/response payloads
- **API key security** via X-API-Key header for mutating operations
- **Reservation TTL** with automatic expiration (15 min default)
- **Idempotency keys** prevent duplicate reservations on retry
- **State machine** for reservations (pending→confirmed/cancelled/expired) and orders
- **Pagination** for order lookup with cursor-based traversal
- **Comprehensive tests** covering happy paths, error conditions, and edge cases (insufficient stock, expired reservations, unauthorized access, pagination)
