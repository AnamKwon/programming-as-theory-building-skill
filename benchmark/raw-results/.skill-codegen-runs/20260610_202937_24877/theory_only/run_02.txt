## Summary of Implementation

**Architecture:**
- **Repository Pattern**: All database access isolated in `repository.py`
- **Service Layer**: Business logic in `service.py` using repository methods

4. ✅ Stock deduction on create, restoration on cancel/expire
5. ✅ State validation (PENDING-only operations)
6. ✅ API token authentication on all mutations
7. ✅ Paginated orders listing
8. ✅ Complete test coverage (unit + integration)
